# Chai & Rain - The Midnight Tapri

A browser-first midnight tea stall: neon lights, a steaming glass of cutting chai, rain on the screen and soulful music, made to leave running in a tab.

## Features

- **Music player** with a spinning cover, progress bar, previous/next and auto-advance. Songs stream through the official YouTube player (nothing is downloaded or re-hosted).
- **Barish mode**: rain streaks and droplets sliding down the screen, lightning with thunder, distant tyres splashing through puddles, and a rain volume slider. Off by default.
- **Order another cutting chai**: boiling and pouring sounds, the glass refills and the neon palette shifts. Four palettes are also available from the header.
- **Tapri one-liners** that pop up between songs.
- About and FAQ sections, loaded from the backend.
- Optional photo banner: drop `banner.jpg` (and `mobile.png`) into `frontend/public/img/` to replace the illustration.

## Tech stack

- **Frontend:** React 18, Vite, plain CSS, Web Audio API
- **Backend:** Python, Flask
- **Hosting:** Vercel (static frontend plus a Flask function)

## Project structure

```
backend/
  app.py            Flask API (tracks, quotes, FAQ, features) and static file serving
  content.py        Quotes, FAQ and About text
  playlist.json     Your songs (YouTube links or IDs)
  blocked.json      Videos that cannot be embedded (hidden automatically)
  synth_tracks.py   Generates demo tracks when no playlist is set
frontend/
  src/              React components, audio and rain code
  public/           robots.txt and optional banner images
api/index.py        Vercel entry point for the Flask app
vercel.json         Vercel configuration
```

## Run locally

Requirements: Python 3.10+ and Node.js 18+.

```bash
# 1. Build the frontend
cd frontend
npm install
npm run build

# 2. Start the backend (serves the API and the built site)
cd ../backend
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000.

For live frontend editing, run `npm run dev` in `frontend/` while the backend is running; Vite proxies `/api` to Flask.

## Adding songs

Edit `backend/playlist.json`. Each entry is a YouTube link or video ID, or an object with an optional title and artist:

```json
[
  "https://www.youtube.com/watch?v=VIDEO_ID",
  { "title": "My title", "youtube": "VIDEO_ID" }
]
```

Reload the page to see changes. Only add videos you are allowed to play.

Some uploads are not allowed to play outside YouTube (the owner disabled embedding). The player skips these and remembers them, and `backend/blocked.json` lists the ones already known. To re-test a video, remove its ID from that file.

If `playlist.json` is empty, the site plays short demo tracks generated by `synth_tracks.py`.

> Playback needs a normal desktop or mobile browser such as Chrome or Edge. Some embedded browsers (for example inside an editor) cannot decode YouTube video.

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import it at https://vercel.com/new and accept the defaults. `vercel.json` handles the build and routing.
3. Every `git push` redeploys the site.

The site is marked `noindex`, so search engines will not list it; only people with the link will find it. On Vercel, the backend cannot save files, so reporting blocked videos is switched off and the committed `blocked.json` is used.

## Environment variables

| Variable | Default | Purpose |
|---|---|---|
| `ALLOW_BLOCK_REPORTS` | `1` locally, `0` on Vercel | Let the player report unplayable videos to the backend |
